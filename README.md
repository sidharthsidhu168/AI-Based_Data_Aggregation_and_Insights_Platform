# 🚀 AI-Based Data Aggregation and Insights Platform

## 📌 Overview

The **AI-Based Data Aggregation and Insights Platform** is a full-stack web application designed to collect, process, and visualize data from multiple sources. It provides meaningful insights using interactive dashboards and intelligent analysis techniques.

This project demonstrates how modern technologies like **React.js** and **Flask** can be combined to build scalable data-driven applications.

---

## 🎯 Objectives

* Aggregate data from APIs or datasets
* Analyze and process data efficiently
* Display insights using interactive visualizations
* Provide a clean and user-friendly dashboard

---

## 🛠️ Tech Stack

### Frontend

* React.js
* JavaScript (ES6+)
* HTML5 & CSS3

### Backend

* Python (Flask)
* REST APIs

### Tools & Libraries

* Axios (API requests)
* Chart libraries (for visualization)

## ⚙️ Installation & Setup

### 🔹 1. Clone the Repository

```
git clone https://github.com/sidharthsidhu168/AI-Based_Data_Aggregation_and_Insights_Platform.git
cd AI-Based_Data_Aggregation_and_Insights_Platform
```

---

### 🔹 2. Setup Backend

```
cd backend
pip install -r requirements.txt
python app.py
```

---

### 🔹 3. Setup Frontend

```
cd frontend
npm install
npm run dev
```

---

## 🌐 Usage

1. Start the backend server
2. Start the frontend application
3. Open the browser and navigate to:

```
http://localhost:3000
```

4. View dashboards, charts, and insights
